# Apple Design System

Swift package for shared native components and visual tokens. Product-specific
features stay in their application; reusable app foundations stay in
[`apple-foundations`](../apple-foundations/README.md).

```sh
make build
make test
make format-check
```

Add the package through Xcode or Swift Package Manager and import
`AvgeekDesignSystem`.

Bundled with DNSDeck so a public checkout builds without private dependencies.
