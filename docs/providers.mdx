## Credentials and capabilities

Choose a provider in the connection form to see its credential fields, setup
link, and required permissions. These are defined alongside record types,
zone operations, and TTL rules in the
[provider catalogue](https://github.com/avgeek-oss/DNSDeck/blob/main/DNSDeck/ProviderDefinitions.json).

Providers expose different APIs. A provider that supports record editing may
not support creating zones, changing registrar nameservers, or writing every
record type visible in its console. DNSDeck limits actions to the capabilities
implemented for that provider and protects records it cannot safely rewrite.

For PowerDNS, use HTTPS for remote endpoints. Loopback HTTP is accepted for
local development.

## Verification status

These integrations were recovered from the final native SwiftUI version.
Compilation does not verify current credentials, account eligibility, or
every provider's live API. The repository retains its
[historical implementation ledger](https://github.com/avgeek-oss/DNSDeck/blob/main/PROVIDER_VERIFICATION.md)
and explicit live tests for Cloudflare, GoDaddy, Amazon Route 53, and IONOS.

When reporting an issue, include the provider, app version, operation, and a
redacted error. Never include API credentials or private zone exports.
