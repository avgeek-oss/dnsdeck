DNSDeck brings 24 DNS providers into one SwiftUI app. Connect your accounts,
browse zones, edit records, and use bulk import and export while keeping your
API credentials in Apple Keychain.

## App Store or source

DNSDeck is being prepared for a return to the App Store as a paid app for people
who prefer a ready-to-use download. The restored release is not yet announced
as available. In the meantime, you can build your own copy from the public
[GitHub repository](https://github.com/avgeek-oss/DNSDeck).

The source is licensed under Apache-2.0. Building DNSDeck requires a Mac and
Xcode; running it requires iOS 18.0 or macOS 15.6 or later. There is no server
to deploy or DNSDeck account to create.

## What it includes

- Multiple provider accounts and environments.
- DNS record creation, editing, and deletion with provider-specific controls.
- CSV and BIND zone import, CSV export, and bulk record workflows.
- Native navigation, appearance settings, localization, and app locking.
- A local MCP companion on macOS for compatible clients.

Available operations depend on the provider. Read [Providers](/providers) for
the supported list and setup guidance.
