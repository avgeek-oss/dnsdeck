DNSDeck is a native SwiftUI app for managing DNS accounts, zones, and records
across 24 providers. It connects directly to provider APIs and keeps credentials
in Apple Keychain.

## What you can do

- Group provider accounts into named environments.
- Browse, search, create, edit, and delete supported DNS records.
- Import CSV or BIND zone files, export records, and apply bulk actions.
- Use provider-specific features where supported, including Cloudflare proxy settings.
